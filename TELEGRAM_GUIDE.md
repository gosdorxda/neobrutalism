```

🔹 Type: Food Purchase
📅 [DD MMM YYYY, HH:MM]
💰 −$[X]
🛒 Store: [store name]
📦 Item: [e.g. 25kg Premium Cat Food]
🏦 Wallet: foundation wallet
🔗 Tx: [solcan link]
🧾 Receipt: [link foto nota]

```

**Tipe C — Update saldo (per batch / berkala):**
```
📊 FUND ACTIVITY

🔹 Type: Balance Update
📅 [DD MMM YYYY]
🏦 Creator wallet: [Y] SOL (≈ $[X])
🏦 Foundation wallet: [Y] SOL (≈ $[X])
📝 End of Batch #[N]

Status: [ready for next batch / pending feeding]
```

**Format ringkas (opsional, untuk auto-bot):**
```
[19 Aug, 14:30] +2.45 SOL ($420) | Rewards | Batch #6 | tx
[19 Aug, 16:00] −$380.00 | Food Purchase | Batch #6 | tx + receipt
[19 Aug, 16:05] Balance: 0.12 SOL ($20.60)
```

> Tujuan: member bisa trace tiap dolar dari masuk → keluar → jadi makanan. Kalau ada gap antara rewards masuk vs food beli, tim harus jelasin di topic ini.

## 6. Tone & Posting Tips

- **Bahasa**: English (konsisten sama website). Boleh bilingual kalau perlu, tapi post resmi tetap English.
- **Tone**: formal, conviction, ramah. Bukan hype-lord, bukan "AI-generated" cliché. Hindari em-dash (—).
- **Selalu sertakan proof** di post yang relevan (foto/nota/tx). "Proof over hype."
- **Ulang slogan** secukupnya: "Every swap fills a bowl." / "Fill bowls, not wallets."
- **Jangan janji harga/moon**. Pesannya: feeding cats, bukan ROI.
- **Sapa member** sebagai "Feeders".

## 8. Catatan Bot Fund Activity (opsional, kalau mau otomatis)

Bot watch creator wallet & foundation wallet (Solana). Tiap transaksi:
1. Deteksi tx (in/out).
2. Post ke `#fund-activity` pakai format Tipe A/B (section 5.3).
3. Ambil harga SOL realtime untuk konversi USD (sama kayak `lib/cache.ts` `getSolPrice()`).
4. Saldo update tiap akhir batch (Tipe C).

Bisa pakai layanan wallet alert (mis. Helius webhook / Solana Tracker) atau bot custom Node.

> Sejalan sama `PROJECT_CONTEXT.md` §9: transparansi fund-activity = prioritas fitur.
